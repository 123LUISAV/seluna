## Probar el APK

Instala `Seluna-Entrega.apk` en Android 8.0 o superior. En la primera apertura crea una cuenta de Firebase o entra con una que ya esté registrada en `seluna-app`. Configura el ciclo, registra un síntoma y abre **Estadísticas → Exportar informe de salud en PDF**. Para exponer sin instalar el APK, abre la presentación HTML después de extraer el ZIP completo.
